- One row per item. **Default** is what the game does today. **Cost** is what changing it touches, in plain terms (not a time estimate).
- Write your answer in the last column: `keep`, `change to ...`, or a sentence. A blank means "keep".
- "Where" is a file and line (or a content id) that exists on that commit. Line numbers drift; the ids and constants do not.
- Rows are ordered most consequential first inside each group. Ids (R1, M2 ...) are for your answers and for PLAN §9 afterwards.
- Anything that no longer needs you (a later commit or one of your own answers already settled it) is in the last section, with the commit or file that did it. Skim it; shout if one of them is wrong.
